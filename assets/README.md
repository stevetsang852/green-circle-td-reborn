# Pixel Art Assets

本專案使用**免費、開放授權**的 Pixel 風格資源（CC0 / Public Domain / 可商用且不限制再分享）。

## 推薦資源（均可直接使用）

### 1. Kenney - Tower Defense (Top-Down)
- **License:** CC0 (Public Domain)
- **Link:** https://opengameart.org/content/tower-defense-top-down
- **內容：** 地面資源、道路、塔、敵人、特效、HUD
- **下載：** Tower Defense (top-down).zip

### 2. Kenney - Tower Defense Kit
- **License:** CC0
- **Link:** https://opengameart.org/content/tower-defense-kit
- **內容：** 塔、武器、瓦片等（3D 但可參考，亦有 2D 版本）

### 3. CodeLaboratory - Pixel Tower Defenders Asset Pack
- **License:** Free to use in commercial / non-commercial projects (不可轉售資產本身)
- **Link:** https://codelaboratory.itch.io/pixel-tower-defenders-asset-pack
- **內容：** Pixel 風格塔（多種風格）

### 4. finalbossblues - Pixel Shooter and Towers Asset Pack
- **License:** Public Domain
- **Link:** https://finalbossblues.itch.io/pixel-shooter-towers-asset-pack
- **內容：** 塔、怪物、射擊物、角色

### 5. 其他 CC0 收集
- https://github.com/Tiddybub/2d-assets （大量 CC0 資產分類）
- OpenGameArt 搜尋 "tower defense" + CC0 filter

## 使用建議

1. 下載上述資源
2. 放入 `assets/sprites/` 、`assets/tiles/` 等資料夾
3. 在遊戲中使用時可選擇性標注來源（CC0 不強制要求，但建議做）
4. 避免使用任何有版權限制的資產

## 目錄結構建議

```
assets/
├─ sprites/
│  ├─ towers/
│  ├─ enemies/
│  └─ effects/
├─ tiles/
└─ ui/
```

所有資產都應該是 Pixel 風格，保持統一視覺。
